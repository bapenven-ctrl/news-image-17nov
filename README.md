One image that sums up the world news of Tuesday 17 November 2026,
drawn as a broadsheet front page: "THE WORLD IN ONE DAY". The lead is
the Crimea (Kerch) Bridge strike — "UKRAINE FELLS A SPAN OF THE
CRIMEA BRIDGE" — with five panels (Strait of Hormuz, attributed to
Iran's claim; Trump in Manila; the U.S. AI-chip loophole closure and
Nvidia earnings; the ULA Vulcan failure that lost 40 Amazon Leo
satellites; Japan scrambling jets) and an "Also today" strip (Gaza,
Sudan, the EU charge against Temu, Mongolia's president). Ten
verified stories, five continents, every headline set in real type —
the image was rendered deterministically with Pillow, never
AI-generated, so no text is garbled.

The entry program is deliberately simple: `main.py` (Python 3.13,
standard library only) copies the committed `entry.png` to the
output path, so both harness runs write identical bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
